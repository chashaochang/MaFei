## 图像处理与隐私

- 首批 `phone-library.webp`、`phone-series.webp` 保留无损 WebP；`tablet-home.jpg`、`tablet-library.jpg` 保留 HDC 原始 JPEG。
- 功能扩充批次仅做矩形裁切与 WebP 压缩（quality=90）；侧栏展开批次使用 quality=92，并做下述明确标注的隐私遮挡。未替换海报、改变界面布局或合成播放画面，裁切后的尺寸见上表。
- 新增手机与平板图裁去系统状态栏，避免发布通知图标等个人设备状态；手机电影详情另外裁去包含服务器文件路径的底部区域。分季目录明确标为局部截图，不隐瞒裁切。
- 首页与媒体库改为侧栏展开态，保留导航、分组和当前选中项。两张侧栏图依据 UI 树定位原图 `[30,1615][570,1815]` 的账号按钮区域，用不透明色块覆盖头像与昵称并写明“账号信息已隐藏”；该区域是后期隐私处理，不是 App 控件。其余平板功能图保留原采集状态。
- 未使用服务器配置、错误页或黑屏作为展示图。最终图片已逐张检查，未展示账号、邮箱、服务器地址、令牌、设备标识、文件路径或个人通知内容。
- 交付文件不携带 EXIF、定位或设备序列号等元数据。原始 UI 树与含个人信息的候选图只保留在本机，不加入仓库。

## 版本与验证边界

截图来自设备当时安装的开发包，不代表商店版本，也不声明与某个纯提交的源码树完全一致。选集、字幕、音轨、风格等截图只证明界面与入口存在，不等于播放、偏好切换或全平台兼容性已验收。本次没有用黑屏占位或其他画面伪装播放器效果。
