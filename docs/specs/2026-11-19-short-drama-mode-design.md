# MaFei 短剧模式

短剧采用「点开即播」：从浏览入口直接进入竖滑播放器，在播放器选集，点剧名进入短剧详情。普通媒体维持现有入口、详情与播放行为。参考红果的播放页、选集面板和详情页布局，控件、反馈与适配遵循 [MaFei UI 规范](../../common/ui/UI_POLICY.md)。

## 识别规则

- 只自动识别。所属媒体库当前名称包含「短剧」（如「精选短剧」）时，剧集、季、分集和独立视频进入短剧模式。库和作品均无手动设置；旧设置不再读取，不保存识别结果。不根据视频时长、方向、海报比例或技术标签推断。
- 判定使用已知库归属；首页、搜索、收藏和历史缺字段时通过作品或所属剧集补全归属。查不到明确归属时按普通媒体走。补全请求失败不覆盖已知事实，必要时提供原操作的重试；取消或切换账号后的结果不得触发导航。

## 入口与续播

| 用户动作 | 短剧目标 |
| --- | --- |
| 点首页、媒体库、搜索、收藏或历史中的分集 | 直接播放该集，沿用现有单集进度规则 |
| 点整部剧或收藏中的剧集 | 恢复最近有观看记录的可播放集及进度；没有记录时播第一可播放集 |
| 点独立视频 | 直接续播该视频；没有上下集或选集控件 |
| 点某一季 | 优先续看该季内最近观看的一集，否则播该季第一可播放集 |
| 点播放器中的剧名 | 打开当前作品的短剧详情，保留当前播放器会话 |

入口共享同一判定，不在卡片或 Feature Screen 内做分类。进入短剧播放器不把普通详情压入返回栈；退出后回到原入口，保留搜索、列表或历史位置。点媒体库本身仍进入该库浏览。

播放目标和集序由浏览播放选择能力解析。独立视频与分集可先起播，不等待整个集列表加载。剧集以现有剧集及季顺序组织，向数据源分页获取、按 ID 去重并维持当前集锚点；跨分页及季边界仍可换集，不把单次请求上限当总集数。仅在来源提供可信总量或列表取完后显示「全 N 集」。队列加载失败保留当前集、已加载列表和重试入口；没有任何可播目标时留在原入口，通过标准反馈提供重试。

## 播放器与选集

- 手机采用黑底全屏竖向翻页。顶部显示返回、集号和倍速（引擎支持时），同一播放会话中换集保留所选倍速。主体为真实视频，横版提供显式全屏入口。底部按剧名、剧集简介、进度条、选集排列；简介缺失时用非空的本集简介，折叠两行，超出时可展开和收起。收藏留在选集与详情，不展示后端不支持的轨道或社交按钮。宽窗口使用受约束的内容宽度，并保留键盘或指针可用的选集入口。
- 保留当前及相邻两集各自的播放器实例和原生画面。邻页预备并暂停，拖动时露出已就绪的真实首帧；滑动取消不切换播放权，停稳后先暂停旧集，再让新集出声和上报。预备未就绪时按实际状态显示封面或加载，不能把封面当作已就绪帧。播完有下一集时自动翻页；末集停在本剧，不自动换剧。
- 点剧名暂停当前集，详情不创建播放器。返回时保持同一集和位置，恢复打开详情前的播放或暂停意图；「继续播放」明确恢复播放。进入、退出横屏全屏也复用该集的实例与进度。退出播放器或切换账号释放全部短剧实例；快速滑动、晚到回调、后台切换不得引发串音或写错进度。
- 分类与平台能力分开。未提供多实例宿主的平台或构建，对已识别的短剧仍直达普通播放器，保留目标集和进度。短剧宿主明确不支持的流也可改用普通播放器；一般网络错误留在当前短剧会话重试，不自动换引擎。普通媒体路径不变。保留现有 HarmonyOS 开发候选与正式构建隔离，未验收的 SDK 不进入正式包。
- HarmonyOS 开发包的鉴权流和倍速依赖支持 `MultiInstancePlayer.setPlaybackSpeed`、`httpHeaders` 和 `allowInsecureTls` 的候选 SDK。旧版只支持不需要额外请求头或证书例外的流；开发用 HAR 不随应用源码分发。

### 进度拖动态

- 正常播放控制区与拖动预览区是两套互斥布局。开始拖动后，剧名、简介和常态细进度条整组隐藏，隐藏的控件不响应操作；原位置由独立的拖动预览区接管。顶部集号、主视频、横版全屏入口和底部选集保持原位。
- 拖动态从上到下是居中的目标帧缩略图、目标时间与总时长（如 `00:35 / 01:29`）、专用拖动条。缩略图内容随目标时间更新，容器不跟手指移动。无法取图时只显示时间和拖动条，不用海报冒充目标帧。
- 切换布局不能打断同一次拖动或重建主播放器。拖动期间不触发翻页或反复跳转；松手只提交一次跳转，取消则不提交。结束后恢复常态控制区，已结束或已换集的预览结果不再显示。

### 选集面板

- 手机从底部展开约半屏，上方保留同一视频画面，按原比例适配剩余空间。开合不重建播放器、不改变当前播放或暂停意图；面板展开时拦截背景的手动翻页，网格滚动与分段滑动只操作面板。系统返回先关闭面板。
- 顶部显示小海报、可进入详情的剧名和真实集数，右侧复用「收藏」。完结状态仅在数据源明确提供时显示。不加入「永久免费」「更多好剧」或另开追剧入口。
- 集数分段横向滚动，每段 30 集，例如「1–30」「31–60」，170 集的末段为「151–170」。有多季时先选季，再显示该季的分段和集号网格。常见手机宽度显示六列，窄屏按可用宽度减列，保留足够触控面积；底部避让系统手势区。
- 打开面板时定位到当前集所在分段、滚动到当前集并高亮。切换分段只浏览、不切集；点集后收起面板并在同一会话切集，点当前集只收起，不重播。自动下一集更新当前集状态，不抢走面板内的浏览位置；再次打开时重新定位到实际播放集。已确认只有一集的内容不显示选集。

## 短剧详情

顶部是紧凑的海报、剧名、集数和真实分类信息；使用海报取色的背景与足够的文字对比。正文展示可展开的剧情简介，有真实关联数据时才展示相关作品。底部固定「收藏」与「继续播放」，收藏使用现有媒体事实同步，剧集收藏作用于整部作品。

详情由播放器剧名进入，正文复用同一分季、分段选集网格并高亮当前集。点集返回当前播放器会话，开始所选集；关闭详情仍恢复打开前的播放意图。无数据的热度、评论、关注和推荐不显示；不把红果截图、品牌图标或示例海报当作项目素材。

## 状态边界与验收

- 共享入口基于当前账号的媒体归属自动分类，并将结果交给现有导航或播放意图；续播目标与分页请求由浏览控制器处理。路由和壳层映射保持纯数据，绑定只取所需能力。短剧会话独占其播放状态，收藏等共享事实经现有统一模型发布。
- 行为测试覆盖库名匹配与改名、归属补全、入口一致性、普通媒体回归、请求竞争、分页跨界、独立视频、续播、详情返回及能力降级；运行应用边界、依赖边界、反馈门禁及受影响平台的测试或编译。
- 使用 `.dev` 开发包验证双向拖动时的相邻真实帧、停稳后起播时间、单路音频、自动下一集、进度不串集、全屏复用、详情往返和退出释放。用长短标题、横竖版视频、百集剧和浅深海报核对手机及宽屏，检查选集开合不打断画面、跨段定位正确、网格滚动不切集；自动点击先读取布局树真实坐标。自动测试、模拟器、真机和视觉结果分开报告。
