# 源文件规模门禁

`node scripts/verify-source-size.mjs` 检查所有活动模块 `src/*Main/` 中的 Kotlin 源码，包括 Screen、Adapter 和普通辅助文件。测试、vendor、生成目录与旧 ArkTS 不参与。物理行数衡量阅读体量，不替代架构或行为测试。

新文件默认不超过 800 行。首次基线在 `scripts/source-size-budgets.json`，对已存在的大文件按本轮检查时提交源码与完整工作区的较大值设置上限，以保留既有未提交修改；结构拆分完成后下调或移除相应例外。不要为新辅助文件增加例外。

门禁同时读取 Git 基线中的预算，禁止提高默认值、增大现有例外或添加新例外。本地默认与 HEAD 比较；CI 用 `MAFEI_SIZE_BASE_REF` 指定 PR base / push before。基线提交不存在时检查失败，必须先 fetch，不能静默忽略；第一次引入门禁时允许初始化清单。

拆分应按稳定职责，保留参数、状态和调用顺序。长函数若仍有紧密状态关系，明确保留并逐步治理，不为了行数新造全局上下文或改变产品行为。已拆小的文件可删除例外；未删除的预算也只允许下降。
