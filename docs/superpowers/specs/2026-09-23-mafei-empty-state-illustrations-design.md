# MaFei 空状态插画设计规格

## 视觉方向

整套插画采用“毛玻璃轻拟态”风格：半透明的乳白与冷灰表面、浅层叠关系、柔和内阴影和很轻的接触阴影。画面保持系统级的克制感，插画是一个安静的状态符号，不承担复杂场景叙事。

视觉目标是让插画在深色页面上有清晰轮廓，在浅色页面上仍然保持层次；主体有轻微浮起感，但整体接近平面图标，不呈现产品摄影的厚重体积。

## 统一造型规则

- 每张插画使用一个主物件，必要时使用两到三个同形叠层表达媒体集合。
- 主体采用圆角方形、圆角矩形和少量圆形，保持统一的圆角比例与边缘厚度。
- 主物件占 1024×1024 母版画布约 52%–64%，四周保留稳定安全区。
- 表面使用低对比的乳白、冰蓝灰和 MaFei 蓝；状态警示可使用低饱和珊瑚色。
- 玻璃感来自透明度、背景模糊和边缘高光；轻拟态来自内凹/外凸的微弱明暗关系。
- 阴影保持短、软、低透明度，画面使用克制的反射与浅透视。
- 插画母版使用透明背景；深色和浅色页面通过环境底色呈现不同的材质层次。

## 状态套系

| 状态 | 主物件 | 语义动作 | 辅助色 |
| --- | --- | --- | --- |
| 暂无媒体库 | 三层轻拟态媒体页 | 前页嵌入播放符号 | MaFei 蓝 |
| 暂无收藏 | 单张轻拟态媒体页 | 中央收藏符号轻微凹入 | MaFei 蓝或低饱和珊瑚 |
| 暂无观看记录 | 单张轻拟态媒体页 | 小型时间盘或进度环 | MaFei 蓝 |
| 没有搜索结果 | 单张轻拟态媒体页 | 搜索环与短柄 | MaFei 蓝 |
| 加载失败 | 单张轻拟态媒体页 | 中央状态提示符号 | 低饱和珊瑚 |

所有状态共享同一主物件比例、圆角、表面处理、光源方向和阴影强度，仅替换语义符号与叠层数量。

## 页面使用

空状态组件由共享 UI 提供统一展示实现，页面只传入状态、标题、说明和可选操作。插画作为装饰内容，标题和说明提供可访问的状态信息，操作按钮负责下一步任务。

手机端插画建议显示在 152–192dp 区间，宽屏端显示在 192–240dp 区间；插画与标题之间保留 20–24dp，说明与主操作之间保留 12–16dp。状态区域维持明显留白，插画独立置于页面内容区。

出现动画采用 180–220ms 的淡入与轻微上移，位移不超过 8dp；交互按钮沿用现有按钮和玻璃组件的行为，插画本身不承担点击命中区。

## 资源与验收

- 先生成 1024×1024 的成品级参考图，再整理为透明 PNG 母版和 Compose 多平台资源。
- 首批至少覆盖上述五个状态，并在同一页面同时检查深色/浅色背景、手机/宽屏尺寸和 1×/2× 缩放。
- 验收重点是状态识别、主体轮廓、浅层材质、文字可读性和不同页面之间的统一性。
- 资源接入前确认共享 UI 只有一个空状态展示实现，避免各 Feature 各自复制布局或动画。
