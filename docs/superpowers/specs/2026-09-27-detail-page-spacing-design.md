# 详情页内容节奏设计

## 目标

让视频详情页和季详情页的内容形成稳定的阅读节奏：同一组内容保持紧凑，不同组内容有明确留白；不新增玻璃卡片、分割线或业务文案，不改变鸿蒙版已有内容顺序。

## 分组规则

1. 播放、收藏、已看和音视频选择属于同一个操作组。
2. 简介、季列表、演职人员、媒体信息、外部链接分别是内容组。
3. 文件信息和视频信息属于媒体信息组内的两个子组。

## 间距契约

| 关系 | 间距 |
| --- | ---: |
| 操作组内部控件 | 12dp |
| 内容组之间 | 28dp |
| 分区标题到内容 | 12dp |
| 媒体信息子组之间 | 20dp |
| 数据项标签和值 | 10dp |
| 页面底部安全区后的收尾 | 30dp + safe area |

详情页间距必须通过公共常量表达，禁止在页面中继续散落同一语义的裸 `Spacer` 数值。加载指示器不得在隐藏时改变内容组之间的节奏。

## 保持不变

- 继续沿用鸿蒙版的视频详情内容和顺序。
- 不把普通内容区批量包装成玻璃卡片。
- 不新增分割线或标题文案来制造分组。
- 不改变移动端和大屏端的导航结构，只统一详情内容的垂直节奏。

## 验收

- 手机、平板和桌面窗口中，组内间距稳定、组间间距明显。
- 详情数据缺失或异步加载时，不出现额外空洞或内容跳动。
- 视频详情和季详情使用同一套间距常量。
- 详情模块的桌面、Android、鸿蒙编译和已有测试通过。
