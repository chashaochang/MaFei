# 媒体卡片悬停操作与大屏首页最近添加设计

日期：2026-09-29  
状态：已获用户确认，等待实施计划  
范围：大屏首页、通用媒体卡片、媒体状态操作

## 1. 问题与目标

当前有四个相互关联的问题：

1. 首页“继续观看”和“接下来”使用横版媒体卡片，没有悬停播放、已观看和收藏操作。
2. 大屏首页把各媒体库的最近添加放到了“最近添加”二级页面，首页只显示合并后的单排内容。
3. 列表卡片的悬停操作只对首个可操作项表现正常；后续项目会被详情页复用的全局操作锁阻塞。
4. 悬停操作只显示动作，不反映当前 `isPlayed` / `isFavorite`，操作完成后也不能立即同步所有列表。

目标是建立一套公共的卡片悬停操作层，并让大屏首页按 Jellyfin 的信息结构展示各媒体库的最近添加；手机现有 Floating Tabs 和首页结构不改变。

## 2. 交互设计

### 2.1 统一悬停层

以下卡片统一使用同一个公共悬停层：

- 继续观看
- 接下来
- 大屏首页各媒体库的最近添加
- 媒体库列表
- 收藏列表
- 搜索结果
- 其他复用 `MediaCard` / `LegacyVideoCard` 的列表

悬停或键盘聚焦时：

- 海报上显示轻量黑色半透明遮罩。
- 中央显示播放按钮。
- 底部显示已观看和收藏按钮。
- 标题变为主题强调色。
- 不增加“更多”按钮，不改变原有点击卡片打开详情的行为。

已观看和收藏按钮必须显示当前状态。选中状态使用现有 MaFei 图标和主题强调色表达，未选中状态保持现有白色线性图标；不新增 Material 卡片或独立视觉体系。

### 2.2 操作状态

悬停层接收 `isWatched` 与 `isFavorite`，不通过字符串状态推断。点击后先在当前状态树中立即反映目标状态，网络操作在后台执行；失败时恢复原状态并沿用现有错误反馈通道。

同一媒体的操作需要防重复提交，但不同媒体之间互不阻塞；收藏和已观看也不能共享详情页的全局 busy 锁。

### 2.3 大屏首页最近添加

仅对 `Sidebar` / `Rail` 等大屏布局调整：

- 首页在“继续观看”“接下来”之后，按媒体库分别渲染“最近添加 · 媒体库名称”横向内容行。
- 每行只显示该媒体库的最近添加，不再把各媒体库合并成一行。
- 每行的更多入口进入对应媒体库列表，而不是统一的“最近添加”二级页面。
- 手机继续使用现有单个 Floating Tab 对应的最近添加内容，不改变手机信息结构。
- 旧的最近添加二级页面不再作为大屏首页入口；是否保留内部路由由实施阶段按引用结果清理，不新增兼容分支。

## 3. 组件与数据边界

### 3.1 `common:ui`

- 将当前 `MediaCardHoverOverlay` 扩展为公共可复用组件。
- 组件只负责悬停/聚焦视觉和动作回调，不持有媒体数据或执行网络请求。
- `MediaCard`、`LegacyVideoCard` 和横版首页 shelf 统一传入媒体状态与回调。

### 3.2 `MediaBrowser`

- 保留 `replaceUserData` 对首页、媒体库、收藏、搜索、播放历史和详情数据的统一更新能力。
- 将列表媒体操作从 `detailActionBusy` 中拆出，使用媒体/操作粒度的防重复提交状态。
- 状态更新必须覆盖 `homeFeed`、`homeLatestByCollection`、`items`、`favoriteItems`、`searchItems`、`historyItems` 和详情相关数据。
- 不修改 Provider API、Jellyfin/FNOS 端点或旧数据兼容逻辑。

### 3.3 首页数据加载

- 大屏首页进入时并行触发各媒体库的 `loadHomeLatest`，继续使用现有按媒体库缓存和错误状态。
- 手机只加载当前 Floating Tab 所需的 feed，避免额外网络请求和布局污染。
- 最近添加行沿用现有 `HomeMediaShelf` 的图片、标题、副标题和进度展示，不重新定义媒体文案。

## 4. 失败与边界行为

- Provider 不支持收藏或已观看编辑时，按钮保持不可用的现有表现，不伪造成功状态。
- 单个媒体库最近添加加载失败，只影响该行，并提供现有重试入口；其他媒体库行继续显示。
- 空媒体库显示现有空状态，不插入 Material 默认组件。
- 大屏窗口缩放、侧栏收起和展开只改变行宽与卡片数量，不改变媒体库分组语义。
- 不为开发版脏数据增加兼容路径。

## 5. 验证门槛

### 单元/组件验证

- `MediaCard`、`LegacyVideoCard` 和横版 shelf 都能显示悬停层。
- `isWatched` / `isFavorite` 初始状态正确，点击后状态立即切换。
- 同一列表中至少两个不同媒体可连续执行收藏和已观看操作。
- 收藏和已观看并发操作互不阻塞；失败时仅回滚对应媒体和操作。
- 状态同步覆盖首页、媒体库、收藏、搜索和详情相关列表。

### 布局验证

- 大屏首页显示“继续观看”“接下来”以及按媒体库拆分的最近添加行。
- 手机首页 Floating Tabs 与原有最近添加结构保持不变。
- 大屏收起/展开侧栏后，各最近添加行不重复、不跳转到统一最近添加页。
- 宽度变化时横向 shelf 可滚动，悬停层不被卡片边界裁切或被列表层遮挡。
