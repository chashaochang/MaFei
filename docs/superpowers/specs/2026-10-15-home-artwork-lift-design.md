# 首页封面抬起样板

用户已确认首页样板的抬起效果及半透明播放按钮，继续统一到其他媒体卡片。各页面边界和命中分别回归。

## 依据与边界

- 已查看 [Plex 官方悬停示例](https://support.plex.tv/articles/200484203-interface-overview/)：封面承载播放和附加操作，文字位于封面外。该示例不是最新客户端的动态实测。
- 已查看 [Infuse 官方界面图](https://firecore.com/infuse)：对照封面、文字、列表的层级，不从静态图推断动画。
- 已阅读 [Apple 指针规范](https://developer.apple.com/design/human-interface-guidelines/pointing-devices)：缩放、阴影和周围空间整体设计，按输入方式响应。
- 本轮采用用户确认的“封面抬起＋操作浮现”。不再要求流光或粗白边。

## 实现

- 共享组件采用唯一的已确认实现，移除首页样板开关和旧流光分支。媒体库、收藏、搜索、最近添加、演员作品、季/剧集与播放历史统一封面反馈，保留各自的数据、标题和既有操作。
- 封面整体放大 9%，底边锚定并向上移动 2dp，柔和投影和弱边缘高光。标题和副标题的尺寸、位置不变。
- 稳定悬停 80ms 后显示播放与已有快捷操作，约 140ms 淡入；移出淡出。封面约 200ms 过渡，不做持续逐帧特效。
- 保持真实海报的亮度，仅在按钮附近增加局部可读性底色。播放使用实心白色三角和圆形深色半透明背景；已观看、收藏并列放在右下。播放通常居中，紧凑横图靠左避开右侧操作组。
- 列表预留放大空间，悬停条目提升绘制层级，首尾不裁切；快速离开时保留退场绘制层级。
- 数据、导航、播放事件、账号状态不变。触屏不出现悬停控制；键盘有稳定焦点反馈。

## 验证

自动化检查放大范围、首尾/网格边缘、标题位置、快捷操作实际命中、快速扫过、退出/失焦后静止及触控行为。
用真实媒体封面做少量窄/宽、深/浅、静止/悬停/按压对照，再运行最新 Java 版供用户体验。不将自动化通过称为视觉通过。
